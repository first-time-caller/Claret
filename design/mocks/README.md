# Design mock-ups (23 Oct 2026)

Static iPhone frames for choosing a direction before building further. Example content only: wines, prices and shops are illustrative.

- `claret-A-the-glass.png`: immersive Liquid Glass; the screen takes the wine's colour.
- `claret-B-the-list.png`: editorial, like a merchant's printed list.
- `claret-C-stripped-back.png`: one answer and a scan button.
- `claret-beyond-the-app.png`: fridge-timer Live Activity, Dynamic Island, widgets, Control Centre and Action Button (native app only).

`mocks.html` is the source. Rendered with Newsreader, DM Mono and Inter as stand-ins for New York, SF Mono and SF.
